# 开发日志

## 2026-05-01

### 本次目标

使用 Vue 继续整理并美化个人导航首页，同时修复布局、滚动和交互细节问题。

### 主要改动

1. 完成首页视觉重构

- 将页面整理为更明确的左右双栏结构
- 左栏聚焦个人信息、快捷动作、搜索预设和说明卡片
- 右栏承载一言、时间、快捷操作和链接导航
- 补充统一的玻璃拟态卡片、渐变、背景氛围层

2. 接管搜索模块交互

- 使用 Vue 控制搜索框展开和收起
- 加入搜索引擎切换与自定义引擎管理
- 增加快速搜索预设词

3. 优化链接展示方式

- 给常用站点补充描述和标签
- 将原本简单入口改为信息密度更高的链接卡片

4. 精简页面内容

- 删除 `workspace-overview cards`
- 删除 `status-card cards`
- 保留对首页有实际价值的导航、搜索、天气、音乐等模块

5. 修复布局问题

- 搜索框展开后与时间卡片重叠的问题已修复
- 页面从固定整屏布局改为可滚动布局
- footer 改回文档流，不再遮挡内容
- 统一左右栏宽度关系和部件节奏，降低视觉参差

6. 修复鼠标特效偏移问题

- 将鼠标光效元素移出带 `transform` 的容器
- 使用 `fixed + translate3d` 修正偏移

### 涉及文件

- `index.html`
- `css/theme.css`
- `css/weather.css`
- `css/music-player.css`
- `js/app.js`
- `js/weather-app.js`

### 结果

- 页面已从旧的静态风格升级为更稳定的 Vue 单页结构
- 视觉统一性、功能组织和可维护性都有明显提升

### 当前遗留事项

- `theme.css` 仍保留部分历史样式，后续可以继续收敛
- 外部天气、壁纸、音乐接口仍依赖第三方服务稳定性
- README 和文档在本次开发后已补齐，但还可以继续扩展截图和部署说明
