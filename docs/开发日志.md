# 开发日志

## 2026-05-06

### 本次目标

补齐仓库文档与版本信息，同时收敛搜索、天气和壁纸相关细节，完成本轮代码上传。

### 主要改动

1. 收敛搜索引擎配置

- 默认搜索入口继续保留 Bing，但统一切到 `https://cn.bing.com/`
- 默认搜索引擎图标改为 Font Awesome 内置图标，避免依赖远程 favicon
- 读取和写入搜索引擎 Cookie 时增加规范化逻辑，减少旧配置残留带来的显示问题

2. 增强天气模块容错

- 天气接口改为 `wttr.in` 的中文 JSON 数据流
- 增加 8 秒超时控制和最近一次成功数据的本地缓存
- 首次请求失败时自动回退到默认城市 `青岛`
- 在 `file://` 直接打开页面时给出更明确的提示，提醒通过本地静态服务器访问
- 对风向、湿度、日期和未来天气文案做统一清洗，提高展示稳定性

3. 调整壁纸与静态资源依赖

- 随机动漫壁纸源切换到 `api.btstu.cn`
- 清理部分对第三方小图标资源的直接依赖，减少静态页外链资源风险

4. 同步发布文档

- 更新 `README.md`、`README.zh-CN.md`、`PROJECT_SUMMARY.md`、`CHANGELOG.md`
- 补充 `docs/技术文档.md` 中关于搜索与天气模块的最新实现说明
- 将版本号从 `1.0.0` 提升到 `1.0.1`
- 计划提交并推送到 `origin/主页`

## 2026-05-01

### 本次目标

使用 Vue 继续整理并美化个人导航首页，同时修复布局、滚动和交互细节问题。

### 主要改动

1. 完成首页视觉重构

- 将页面整理为更明确的左右双栏结构
- 左栏聚焦个人信息、快捷动作、搜索预设和说明卡片
- 右栏承载一言、时间、快捷操作和链接导航
- 补充统一的玻璃拟态卡片、渐变、背景氛围层

2. 接管搜索模块交互

- 使用 Vue 控制搜索框展开和收起
- 加入搜索引擎切换与自定义引擎管理
- 增加快速搜索预设词

3. 优化链接展示方式

- 给常用站点补充描述和标签
- 将原本简单入口改为信息密度更高的链接卡片

4. 精简页面内容

- 删除 `workspace-overview cards`
- 删除 `status-card cards`
- 保留对首页有实际价值的导航、搜索、天气、音乐等模块

5. 修复布局问题

- 搜索框展开后与时间卡片重叠的问题已修复
- 页面从固定整屏布局改为可滚动布局
- footer 改回文档流，不再遮挡内容
- 统一左右栏宽度关系和部件节奏，降低视觉参差

6. 修复鼠标特效偏移问题

- 将鼠标光效元素移出带 `transform` 的容器
- 使用 `fixed + translate3d` 修正偏移

7. 优化链接卡片长文本显示

- 修复备注过长时链接卡片内部排版不规范的问题
- 为标题、备注和标签补充截断与超长字符换行兜底
- 避免长文本把 `col` 高度和右侧标签区域挤乱

8. 修复搜索栏特效定位

- 搜索框底部动画线从通用 `.line` 中拆分为独立 `search-line`
- 解决搜索特效被页面其他分割线样式串改后位置偏移的问题
- 将搜索特效线重新限制在搜索框内部显示

9. 同步线上链接配置

- 处理远端分支差异并完成 GitHub 推送
- 将首页博客入口统一更新为 `https://a.loker.love`
- 保持主按钮、链接卡片和 footer 链接地址一致

10. 优化音乐播放器与壁纸交互

- 音乐播放器增加可折叠的网易云歌单 ID 配置入口
- 支持在播放器弹窗内直接切换并持久化自定义歌单
- 非默认壁纸改为支持重复点击刷新新背景
- 调整壁纸加载流程，减少缓存导致的“重复点击无变化”问题
