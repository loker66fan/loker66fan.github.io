# 技术文档

## 项目概述

这是一个基于 Vue 3 全局构建版本实现的个人导航首页项目，定位是单页静态站点。页面集成了搜索入口、常用站点导航、天气弹窗、音乐播放器、壁纸切换和少量交互动效，适合部署到 GitHub Pages、Vercel 或其他静态托管平台。

当前实现强调三点：

- 不依赖构建工具，直接通过 `index.html` 加载脚本和样式
- 主要交互由 Vue 接管，保留静态站点的部署简洁性
- 样式与功能分层，首页主逻辑、天气模块、音乐模块拆分到不同文件

## 技术栈

- Vue 3 全局构建版：`vendor/vue/vue.global.prod.js`
- 原生 JavaScript：负责页面状态、动画联动、播放器逻辑
- CSS：自定义布局、响应式适配、毛玻璃与渐变视觉
- Bootstrap 栅格基础样式：用于列布局兼容
- Font Awesome：图标系统
- iziToast：顶部消息提示
- APlayer：音乐播放组件
- js-cookie：本地持久化搜索引擎和壁纸配置

## 核心模块说明

### 1. 页面主入口

文件：

- `index.html`
- `js/app.js`
- `css/theme.css`

职责：

- 提供页面骨架
- 挂载 Vue 应用
- 组织左栏信息区和右栏工作台区
- 统一交互入口，如搜索、更多设置、音乐、天气

### 2. 搜索模块

实现位置：

- 模板：`index.html`
- 逻辑：`js/app.js`
- 样式：`css/theme.css`

能力：

- 支持搜索框展开/收起
- 支持多个默认搜索引擎
- 支持切换当前搜索引擎
- 支持新增/删除自定义搜索引擎
- 支持预设搜索词快速填充
- 使用 Cookie 持久化当前搜索引擎与搜索引擎列表

相关数据结构：

- `DEFAULT_ENGINES`
- `SEARCH_PRESETS`
- `searchEngines`
- `currentEngineId`

### 3. 时间与一言模块

实现位置：

- 时间：`js/app.js -> updateTime`
- 一言：`js/app.js -> fetchHitokoto`

能力：

- 每秒更新实时时间显示
- 拉取 `hitokoto` 接口展示短句
- 右栏顶部通过两个卡片承接信息密度

### 4. 音乐播放器模块

实现位置：

- 逻辑：`js/app.js`
- 样式：`css/music-player.css`

能力：

- 使用 APlayer 播放网易云歌单
- 歌单接口失败时自动回退到本地兜底列表
- 支持播放、暂停、切歌、拖动进度、音量调节、静音
- 支持随机、单曲循环、列表循环模式切换
- 同步当前歌曲名称和页脚歌词显示

关键方法：

- `tryInitMusic`
- `setupPlayer`
- `musicToggle`
- `musicPrev`
- `musicNext`
- `playSong`
- `seekProgress`

### 5. 天气模块

实现位置：

- `js/weather-app.js`
- `css/weather.css`

能力：

- 独立挂载到 `#weather-app`
- 点击时间卡片唤起天气弹窗
- 调用 `wttr.in` 获取天气与预报
- 自动映射天气图标和文案

模块特征：

- 与主应用解耦
- 使用独立 Vue 实例管理弹窗状态

### 6. 壁纸模块

实现位置：

- `js/app.js -> setWallpaper / initWallpaper`

能力：

- 默认壁纸、本地背景图
- 第三方随机风景、动漫、必应每日图
- 通过 Cookie 记录当前选择

注意：

- 外部随机图源存在稳定性风险
- 默认壁纸目前已切换为本地图片资源，减少白屏和加载失败概率

### 7. 更多面板模块

实现位置：

- 模板：`index.html`
- 样式：`css/theme.css`
- 逻辑：`js/app.js`

能力：

- 管理壁纸
- 管理搜索引擎
- 展示时间胶囊
- 展示杂项链接
- 展示更新日志

## 当前架构特点

优点：

- 纯静态部署，接入简单
- 不需要 Node 构建链路
- 对个人主页场景足够轻量
- Vue 负责状态管理，代码可维护性高于纯 jQuery 方案

限制：

- 没有模块打包，脚本仍然是大文件组织
- 样式文件中仍有历史样式残留，维护成本偏高
- 外部接口较多，网络环境变化会直接影响体验
- 资源版本管理仍以手动 `?v=` 形式为主

## 本轮页面优化总结

本轮主要完成了以下技术调整：

- 将旧版静态首页整理为 Vue 驱动的单页结构
- 重构搜索交互和搜索引擎切换逻辑
- 新增快速搜索预设词能力
- 重构左右栏视觉布局与卡片层级
- 修复搜索栏与时间卡片重叠问题
- 删除多余的 `workspace-overview` 与 `status-card` 模块
- 将页面从整屏固定布局改为可滚动布局
- 调整鼠标光标特效，修复滚动和父级变换带来的偏移

## 后续可优化方向

- 将 `app.js` 再拆分成搜索、播放器、壁纸、布局控制等多个模块
- 为搜索引擎配置和壁纸配置增加数据校验与错误提示
- 将文案、链接、歌单等数据抽离成单独配置文件
- 给天气、音乐、壁纸接口增加失败兜底和超时控制
- 统一清理 `theme.css` 中历史样式，降低重复规则
- 如后续继续扩展，可迁移到 Vite + Vue SFC 结构
